# Data Analysis Coursework

Two report-driven projects: a data-visualization study on how AI is expected to reshape jobs by 2030, and a business-intelligence proposal built on Brazilian public data about higher education and municipal GDP.

Unlike the code-heavy repositories in this profile, the deliverable of both projects is a written report — the code here exists to support the analysis, not the other way around.

| Project | Question | Deliverable |
|---|---|---|
| [Data Visualization](data-visualization/) | Which jobs, industries and skills are most exposed to AI replacement by 2030? | Report + profiling notebook |
| [Business Intelligence](business-intelligence/) | Does the supply of higher-education courses relate to a municipality's economic development? | BI solution proposal (personas, indicators, data sources) |

## Repository structure

```
├── data-visualization
│   ├── notebooks/01_data_profiling.ipynb
│   ├── data/raw/ai_impact_on_jobs_2030.csv
│   └── report/data-visualization-report.pdf
└── business-intelligence
    └── report/business-intelligence-report.pdf
```

> Reports are written in Brazilian Portuguese.
